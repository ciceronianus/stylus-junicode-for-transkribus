# What does this? 
This is a JSON configuration file for [Stylus](https://en.wikipedia.org/wiki/Stylus_(browser_extension)) Browser extension that switches the main font of [Transkribus](https://www.transkribus.org/) ATR/HTR platform to Junicode. 

# Motivation
[Junicode](https://sourceforge.net/projects/junicode/) supports vast variety of special characters, inlcuding a number of MUFI characters. Junicode is also a great option for those using CATMuS transcription guidelines.

# How is the junicode font included?
Junicode font is converted to [Base64](https://en.wikipedia.org/wiki/Base64) and included directly in the configuration file.
